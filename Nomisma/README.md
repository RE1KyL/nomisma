# Nomisma Research Tools

Python research services and managed runtime entry points for the desktop
workspace. See the [project README](../README.md).

- `nomisma_tools/`: economic, financial, data exploration and workbook services.
- `launcher/`: project context, managed providers and approved tool execution.
- `knowledge/`: research planning and validation specifications.
- `.dsh/skills/`: project-level skills, when present.
- `environment.yml`: independent Python 3.11 environment specification.

Research projects, profiles, logs and installed runtimes are not part of the
source release. The development runtime needs local path configuration.
