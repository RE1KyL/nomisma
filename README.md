# nomisma
An open-source desktop workbench for students and researchers in economics, business, finance, and data-intensive disciplines. Bringing together economic research, financial analysis, quantitative modeling, and general-purpose data exploration in one platform/一个面向经济学、管理学、金融学及其他数据密集型学科学生与研究者的开源桌面工作台。集经济研究、金融分析、量化建模与通用数据探索于一体，让数据分析与研究更加便捷
